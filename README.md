# Molecular Energy Minimization — Interactive Laboratory

Interactive educational web application for exploring **molecular energy minimization**, **potential energy surfaces (PES)**, and several numerical optimization methods used in computational chemistry.

The laboratory currently includes:

* Nelder–Mead Simplex
* Steepest Descent
* Conjugate Gradient
* Truncated Newton
* Interactive PES visualizations
* Guided molecular examples
* Computational cost comparison
* Free minimization simulator for small molecules

## Usage

No installation is required.

Clone or download the repository and open:

```text
index.html
```

in a modern web browser.

The application is implemented entirely in **HTML, CSS, JavaScript, and SVG** and runs directly in the browser.


## Purpose

This project is intended as a teaching resource for topics related to:

* Computational Chemistry
* Molecular Modeling
* Molecular Mechanics
* Numerical Optimization
* Potential Energy Surfaces

The molecular models used in the laboratory are simplified for educational purposes and are designed to emphasize the behavior and differences between optimization algorithms.
